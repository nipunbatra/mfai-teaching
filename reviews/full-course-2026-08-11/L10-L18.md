## Lecture notes

### L10 — Numerical differentiation

- Corrected the gradcheck guidance: float64 is recommended, while useful tolerances depend on scale, dtype, and operation; float32 is not categorically invalid.
- Replaced the claim that automatic differentiation is exact to the last bit with the precise distinction: it avoids finite-difference truncation and cancellation but still uses floating-point arithmetic.
- Clarified the error model, optimal step size, central-versus-forward trade-off, forward-mode pass count, and the method-comparison summary.
- Removed manufactured conflict, cliffhanger, referee, and scoreboard language in favour of direct mathematical transitions.
- Residual low-confidence issue: 67 pages is brisk for 80 minutes if every checkpoint is discussed; the complex-step slide is already marked optional and is the natural first omission.

### L11 — Backpropagation

- Corrected absolute timing and universal-model claims. Reverse mode is one backward sweep with a small constant-factor cost relative to the forward computation, not a fixed number of milliseconds for every model.
- Added the necessary scope to the cheap-gradient claim and clarified the forward-/reverse-mode choice by input and output dimension, including the memory trade-off.
- Replaced canned suspense and competitive framing with direct explanations of the computation graph and reverse accumulation.
- Residual low-confidence issue: the micrograd/code walkthrough can consume substantial class time; the framework recap should be shortened if students work through the code live.

### L12 — Continuous distributions

- Repaired the CDF-to-density statements: the derivative identity is asserted only where the CDF is differentiable, with the appropriate continuity qualification for the limiting calculation.
- Clarified why a continuous random variable assigns zero probability to a point and stated the generalized-inverse caveat for inverse-CDF sampling.
- Scoped Gaussian maximum entropy to fixed mean and variance, and removed the overstatement that normalizing flows and diffusion models share the same determinant calculation.
- Corrected the Beta preview: `alpha - 1` and `beta - 1` are interior-mode offsets, whereas Bayesian updating adds observed counts to the parameters themselves.
- Tightened change-of-variables assumptions and softened the description of machine-generated uniform randomness.
- Residual low-confidence issue: the main route is full for 80 minutes; rejection and importance sampling are the natural optional handout material.

### L13 — Multivariate Gaussians

- Replaced “zero assumptions” and “assumes nothing” with the correct maximum-entropy statement under fixed first and second moments.
- Stated the i.i.d. and finite-variance assumptions behind the CLT motivation and added the finite-sample caveat.
- Removed status, aristocrat, and “superpower” rhetoric while preserving the progression from geometry to covariance calculations.
- Residual low-confidence issue: the CLT motivation is intentionally informal; a proof is outside this lecture's scope.

### L14 — Maximum likelihood estimation

- Replaced “every loss is an NLL” with the defensible statement that many standard supervised losses arise from explicit observation models.
- Made the MSE correspondence precise: independent homoskedastic Gaussian observations with fixed variance.
- Added correct-specification, identifiability, and regularity conditions to the consistency claim.
- Corrected the smallest positive float64 scale to approximately `5e-324` and made the Gaussian variance-MLE bias/Bessel-correction note precise.
- Residual low-confidence issue: none beyond the deliberate omission of general asymptotic theory proofs.

### L15 — MAP estimation and conjugate priors

- Separated MLE from MAP correctly: coincidence with a uniform prior is parameterization- and support-dependent, and MLE itself does not assume a flat prior.
- Corrected continuous posterior/evidence notation and distinguished the discrete sum from the continuous integral.
- Clarified Beta pseudo-count language, posterior count updates, concentration, and the conditions under which prior influence washes out.
- Qualified the regularization-as-prior correspondence: it applies to penalties whose exponentials define integrable densities; not every training device or constraint has that interpretation.
- Made the Gaussian/Laplace penalty correspondences explicit.
- Residual low-confidence issue: posterior-predictive and approximation extensions should be treated as optional if the conjugate-update exercises run long.

### L16 — Optimization landscapes

- Added the domain and differentiability assumptions for the Hessian characterization of convexity.
- Completed the least-squares positive-semidefinite calculation and noted that a minimizer requires an attained stationary point, not only a PSD Hessian.
- Corrected the regularization statement: adding a convex regularizer preserves convexity; a nonconvex one need not.
- Scoped convergence claims to appropriate step-size conditions and labelled the random Hessian sign table as a toy illustration rather than a neural-network probability model.
- Removed the overclaim about deep-network local minima and replaced canned “mystery” framing with direct geometry.
- Residual low-confidence issue: at 72 pages this is the largest pacing risk in the block. The Jensen/log-sum-exp extensions and some landscape galleries should be omitted or assigned after class if discussion is active.

### L17 — Gradient descent

- Made the first-order descent argument exact using the `o(eta)` remainder and “sufficiently small” step size.
- Distinguished the L-smooth descent range `0 < eta < 2/L` from the additional assumptions needed for convergence.
- Scoped quadratic local theory to non-degenerate strict minima with a positive-definite local quadratic.
- Repaired the feature-scaling example: the proposed features were exactly collinear, so the true condition number is infinite rather than 1600. The slide now distinguishes the 1600 diagonal scale ratio from collinearity and notes that standardization cannot remove correlation or rank deficiency.
- Qualified the SGD gradient as unbiased only under the stated sampling scheme and removed the claim that a mini-batch step is exactly `n` times cheaper.
- Residual low-confidence issue: timing depends mainly on whether the momentum interaction is run as a live exercise.

### L18 — Second-order optimization

- Required a positive-definite Hessian for the quadratic-model minimizer, replaced explicit inversion with a linear solve, and noted the effect of conditioning.
- Added the assumptions behind local quadratic convergence of Newton's method and the exact threshold for damping to make a Hessian positive definite.
- Expressed Gauss–Newton through least squares, distinguished PSD from PD/full-column-rank cases, and changed the code to `lstsq` so it does not square the condition number through normal equations.
- Corrected the convergence claim: Gauss–Newton is not automatically quadratically convergent.
- Repaired the SciPy description. `curve_fit(method="lm")` uses MINPACK's modified Levenberg–Marquardt implementation with a scaled trust region and QR-based solves; it does not implement the deck's illustrative multiply/divide-by-ten controller exactly. The scalar-damping equation is now explicitly a teaching model.
- Residual low-confidence issue: the optional large-scale first-order comparison is the natural omission if the solver-implementation discussion expands.
